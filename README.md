# Fileion Scoop bucket

```
scoop bucket add fileion https://github.com/fileion/scoop-bucket
scoop install fileion
```

Installs the [Fileion command-line program](https://github.com/fileion/fileion-cli) from its GitHub release files, checked against the SHA-256 on the release. The manifest is written by the release workflow of fileion-cli; do not edit it by hand.
